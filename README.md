Random Password Generator | Python

A Python-based desktop application that generates customizable random passwords through a simple and user-friendly graphical interface.

Overview

The Random Password Generator is a desktop application developed using Python and Tkinter. It allows users to generate passwords according to their preferred length and character requirements, including uppercase letters, lowercase letters, numbers, and special symbols.

The project uses Python's "secrets" module to generate passwords suitable for security-sensitive applications.

Key Features

- Custom Password Length: Generate passwords with a user-defined length.
- Character Customization: Select uppercase letters, lowercase letters, numbers, and special symbols.
- Secure Generation: Uses Python's "secrets" module for random password generation.
- Copy to Clipboard: Copy generated passwords conveniently.
- Clear Functionality: Clear the password field and generate another password.
- Graphical User Interface: Simple and intuitive interface built with Tkinter.
- Input Validation: Handles invalid password length and character-selection inputs.

Getting Started

Prerequisites

- Python 3.x installed on your system.
- Tkinter available with your Python installation.

Installation and Execution

1. Clone this repository:
   
   git clone https://github.com/aditikhobragade-19/Password-Generator.git

2. Navigate to the project directory:
   
   cd Password-Generator

3. Run the application:
   
   python password_generator.py

4. Select your preferred password length and character options, then click Generate Password.
